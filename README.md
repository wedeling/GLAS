# Generalized Laplace Active Subspaces (GLAS)

Jupyter notebooks to reproduce the results of

W.N. Edeling, P.V. Coveney, *Scalable Neural Network Uncertainty Quantification via Generalized Laplace
Active Subspaces*, 2026, (submitted).

## Contents

* `regression_analytic.ipynb`: notebook on the analytic regression problem.
* `regression_concrete.ipynb`: notebook on the UCI concrete compresssive strength problem.
* `classification_reinvent.ipynb`: notebook on the REINVENT problem.
* `data/`: folder with SMILES training data and various precomputed coverage and eigenmodes results.
* `utils/`: python module with various GLAS pytorch subroutines.
* `pre_trained_models/`: folder containing the pre-trained REINVENT LSTM.
* `scoring/`: folder containing REINVENT scoring results and configuration files.
